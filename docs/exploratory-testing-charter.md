# Exploratory Testing Charter

## Goal 
Discover high-impact UX issues in search + filter, correctness, and data consistency in edge cities.
## Focus areas
Search relevance, filter persistence, empty states, partial matches, image missing on listings, listings missing mandatory fields.
## Timebox
45 min
## Heuristics 
Boundary value analysis and testing, error guessing, SFDPOT (Structure, Function, Data, Platform, Operations, Time)
